Use case: stylized-concept
Asset type: ONE production animation sprite atlas, exactly 6 columns by 6 rows, 36 equal square cells, transparent background. Large square canvas. Each cell contains exactly ONE full-body animation frame, generous empty margins; no contact between cells. No labels, text, grid lines, shadows or scenery. Same scale and consistent foot anchor in every cell. Clean thick dark navy lineart, pastel anime chibi, soft cel shading, readable at 72px, polished hand-drawn fighting game animation, coherent volume. All face RIGHT in side three-quarter view. Chronological frames left-to-right then top-to-bottom. Draw real changing limb poses and in-betweens, never duplicate still images. Smooth arcs, overlapping hair/fabric motion, anticipation then rapid strike then held follow-through and recovery. Reference image is STYLE reference and exact character identity reference. Lumi same silver/aqua twin tails, star clips, white/aqua dress, pendant, bare hands. Exact same girl every frame.
