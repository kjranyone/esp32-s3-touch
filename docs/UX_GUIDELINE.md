# UX ガイドライン — 4.0" 480×480 正方形スマートスクリーン

対象実機: **JingCai ESP32-4848S040C_I_Y_3**（4.0 インチ正方形 RGB565 480×480 + GT911 静電容量タッチ）

---

## 1. 物理ディスプレイ基準

| 項目 | 値 | UX 上の意味 |
| :--- | :--- | :--- |
| 表示領域 | **71.8 mm × 71.8 mm** (対角 4.0") | 名刺の短辺より少し大きい正方形 |
| 解像度 / 画素密度 | **480 × 480 px** / **170 PPI** | **1 px ≒ 0.15 mm** |
| 想定視認距離 | **30 〜 50 cm**（卓上／手持ち） | PC モニタ基準の極小文字は判読不能 |
| 操作方法 | 指先タップ＆スワイプ (GT911) | 成人指先の接触幅は **約 9〜11 mm (60〜74 px)** |

> **現行コードの課題**:
> 従来の `3×5` 極小フォントの `scale=1` は **高さ 5 px = 0.75 mm**（現在 `src/beat.cpp` 内に **68 箇所**）。30 cm 離すと点にしか見えず判読不能。また `3×5` グリフ自体が `M / W / N / 8 / B` を判別しづらい。

## 2. タイポグラフィ規定（ハードルール）

### 2.1 フォント刷新
- `3×5` グリフを廃止し、視認性の高い **`5×7` 標準ビットマップフォント**（文字送り `6 px`、行高 `8 px` ベース、ASCII 印字可能文字対応）を採用する。
- Flash 消費は約 665 バイトと極小で、32 行 SRAM バンド合成の 60 fps 性能を損なわない。

### 2.2 最小文字サイズと階層（`12 px` 未満は原則禁止）

| 階層 | 用途 | `5×7` 倍率 | ピクセル高 | 実機物理高 | 視認性目安 (40 cm) |
| :--- | :--- | :---: | :---: | :---: | :--- |
| **禁止** | ~~極小テキスト~~ | `1x` | `7 px` | `1.05 mm` | ✗ 原則禁止（装飾ドット扱いのみ） |
| **T1 (最小)** | 補足数値・タグ・カード内スペック | **`2x`** | **`14 px`** | **`2.1 mm`** | ○ 手持ち〜卓上で明瞭に読める下限 |
| **T2 (標準)** | HUD 主要値・ボタンラベル・字幕 | **`2x〜3x`** | **`14〜21 px`** | **`2.1〜3.1 mm`** | ◎ パッと見て即座に読める標準サイズ |
| **T3 (強調)** | バナー・見出し・ボス名・クリティカル | **`3x〜4x`** | **`21〜28 px`** | **`3.1〜4.2 mm`** | ◎ 卓上 50 cm からでも一目で認識 |
| **T4 (主役)** | タイトルロゴ・決着演出 | **`5x〜6x`** | **`35〜42 px`** | **`5.2〜6.3 mm`** | ◎ 遠目でも画面の主役として成立 |

### 2.3 領域ごとの 1 行文字数上限（`5×7` 基準）
文字を大きくする代わりに、**文章を短く削る**。

| 表示幅 | `2x` (`12 px/字`) 上限 | `3x` (`18 px/字`) 上限 | 設計ルール |
| :--- | :---: | :---: | :--- |
| 全幅 (`460 px`) | **36 文字** | **24 文字** | 字幕・バナーは **20 文字以内** を目標 |
| 3 択カード (`146 px`, 内幅 `132 px`) | **10〜11 文字** | **7 文字** | 単語・略語＋数値のみ（例: `ATK +20%`, `HP 180`） |
| 下部パーティ枠 (`124 px`, 内幅 `116 px`) | **9 文字** | — | 名前＋ランク (`LUMI*2`) とゲージ中心。細かい文字は削る |

## 3. 情報設計（引き算の原則）

72 mm 四方で読める情報量には明確な上限がある。**「全部書く」のではなく「今必要な 3 情報だけ大きく見せる」**。

1. **1 画面の情報階層は最大 3 層まで**
   - 例（戦闘中上部 HUD）: ① **Wave 進行 (`W12/50`)** ② **所持クリスタル (`C 294`)** ③ **BOX 準備状態（色と光で通知）**。
   - `RUN#6`・`CHARM:0`・`POOL 24/64` などのメタ情報は常時 HUD から外し、`INFO / STATUS` パネルに集約する。
2. **テキストではなくビジュアルで語る**
   - HP / MP / 状態異常はバーの色・点滅・短い 3 文字タグ (`PSN` / `BRN` / `SLW` のみ `2x` バッジ) で伝える。
   - レアリティはカード枠色＋短い 1 語 (`N` / `R` / `SR` / `SSR`)。
   - 長い英語フレーバー文（`THE GARDEN BLOOMS IN ETERNAL PEACE.` 等）は削除または短い 2〜3 語へ圧縮する。
3. **コントラストと背景分離**
   - 動く背景・エフェクト上のテキストは必ず **縁取り (`outline`)** または **暗色プレート** を敷く。
   - 暗色背景上の文字輝度は低すぎるグレー（`RGB(0x48..)`）を避け、最小でも `RGB(0x98, 0xB0, 0xCC)` 以上を使う。

| 項目 | 基準値 | 実機物理サイズ | 備考 |
| :--- | :---: | :---: | :--- |

## 5. 全画面別の改修マッピング

| 画面 | 現状の課題 (`scale=1` 乱用箇所) | ガイドライン適用後の方針 |
| :--- | :--- | :--- |
| **タイトル画面** | 上下帯のスペック文・`VER 4.0 * ...`・ボタン副題・実績行が `5 px` で読めない | 飾りの小文字を全廃。ロゴ (`4x〜5x`)・ボタン (`2x〜3x` の太字、副題は `W4/50` 等の短表記 `2x`)・下部プロンプト (`2x`) のみに厳選 |
| **OP アニメーション** | カットイン 3 行目・`TAP TO SKIP >>` が `5 px` | 字幕は 1〜2 行の短い英語フレーズを **`2x` (14px)** でくっきり表示。`SKIP >>` も **`2x`** に拡大 |
| **戦闘 HUD (上下)** | `RUN#` / `BOX COST` / `POOL` / パーティ名・HP 数値・`EMPTY` がすべて `5 px` | 上部 HUD を **`2x` 統一の 2〜3 要素**（`W12/50`・`💎294`・`BOX!`）へ大胆整理。下部パーティ枠も名前 (`2x`)＋太め HP/MP バー中心、細かい数値テキストを削る |
| **3 択ドラフト / 入替** | レア度・ロール・ステータス・スキル説明・`[X]` が `5 px` かつ縦 `30 px` | ヘッダボタン高を **`44〜48 px`** へ拡大。カード内テキストはすべて **`2x` (14px)** 統一、項目を「名前 / 種別 / 主要効果 1〜2 行」に圧縮 |
| **ステータス画面** | 2 カラムに細かい `5 px` 文字列を詰め込みすぎ | 全項目 **`2x` (14px)** 統一。主要ステータス（`ATK / HP / CRIT / SPD / VAMP` 等）に絞って視認性重視の 2 列グリッドへ再構成 |
| **ゲームオーバー / ED** | 結果行・パーティ詳細・TIP が `5 px` | 到達 Wave・リザルト・新解禁通知・`NEW RUN` ボタンを **`2x〜3x`** でメリハリ良く配置し、長文 TIP を削除 |
