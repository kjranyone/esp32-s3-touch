# ゲームデザイン — 『ルミの水晶庭園』(v2: 物理箱庭レイヤー)

放置系インクリメンタル × **物理演算箱庭** × 美少女マスコット。
タップ連打系クリッカーではなく、**自動進行・経営判断主体 + 見て楽しむ物理シミュレーション**。

ハード前提: JingCai ESP32-4848S040C_I_Y_3 (480×480 タッチ, ESP32-S3R8 / PSRAM 8MB,
16MB Flash, WiFi, 常時通電デスク置き運用)

---

## 1. コンセプトの柱

1. **見て楽しむ**: 画面は常時「物理で動く庭園」。水が流れ、砂が積もり、結晶が育つ
2. **放置で育つ**: 電源が入っている間、庭園はリアルタイムで成長し続ける
3. **経営は最小限**: 施設購入・アップグレード・昇華の判断だけ。タップ連打要素なし
4. **見た目 = 経済**: 物理世界で結晶が育つことが、そのままゲームの収入になる

---

## 2. 物理箱庭レイヤー(このゲームの顔)

### 方式
**落下砂モデル (falling-sand cellular automaton)** を採用。
- 論理グリッド **240×240 (1 セル 2×2 px に拡大表示)** — 像素みの可愛い見た目
- 実測想定: 1 パス 2〜4ms @ 240MHz → **30fps で余裕**(将来 480×480 も選択肢)
- グリッドは PSRAM (uint8 × 2 面 ≈ 115KB)、描画は LVGL キャンバス (RGB565, PSRAM 450KB)

### 素材 (v1)

| セル | 挙動 |
|---|---|
| 空 | — |
| 水 | 落下 → 左右に広がる。結晶の種に触れると徐々に消費されて結晶を育てる |
| 砂 | 落下 → 山になる。水の上では沈む |
| 岩(壁) | 動かない地形。タッチで配置/削除できる |
| 結晶の種 | 動かない。水があると対角方向に**結晶成長**する |
| 結晶 | 成長の結果できる地形。**1 セル成長 = ボーナス収入** (きらきら点滅) |

### 施設 = エミッタ (経済と物理の接続点)

| 施設 | 物理世界での振る舞い |
|---|---|
| 晶芽のつぼみ | ときどき水滴を垂らす |
| 水晶の泉 | 泉のように水を噴き出す |
| 鉱脈の巣 | 砂(鉱砂)を吐き出す |
| 星降る塔 | 星屑(成長速度の速い輝く砂)を降らす |
| 月影の祭壇 | 結晶の種をポロポロ落とす |

施設を買うほど物理世界が賑やかになり、結晶がどんどん育つ。
**生産力の上昇が、画面の賑やかさとして直接見える。**

### タッチインタラクション
- 素材選択ボタン (水 / 砂 / 岩 / 消しゴム) → 指でなぞって注ぐ・削る
- ルミに水をかける → 驚く (`07_surprised`)。砂は足元に積もり、ときどき払う
- ルミ本体をなでる (縦スワイプ) → 照れる (`04_pet`) + 一時バフ

### ルミの立ち位置
物理世界の住人として**庭に立っている**(スプライトは物理の影響を受けない)。
背景でなく前景の「庭の中」にいることで、箱庭感が最大化する。

## 3. コアループ (経済レイヤー)

1. 施設が自動でクリスタルを生産 (放置で育つ)
2. クリスタルで施設追加 / アップグレード → 加速
3. 一定規模で **星屑へ昇華 (prestige)** → 恒久バフ付きリセット
4. 電源オフ期間は **オフライン進行** として一括精算 → 復帰時、庭には結晶が生えている

### 資源

| 資源 | 役割 |
|---|---|
| **クリスタル** | メイン通貨。施設・アップグレード購入に使用 |
| **星屑** | 昇華報酬。1 個につき全生産 +1% (恒久) |

## 4. 生産施設 (5 種)

コストは n 個目で `base × 1.15^n`。

| 施設 | 初期コスト | 生産力 | エミッタ表現 |
|---|---|---|---|
| 晶芽のつぼみ | 15 | 0.1 /s | 水滴 |
| 水晶の泉 | 100 | 1 /s | 水流 |
| 鉱脈の巣 | 1,100 | 8 /s | 砂 |
| 星降る塔 | 12,000 | 47 /s | 星屑 |
| 月影の祭壇 | 130,000 | 260 /s | 結晶の種 |

## 5. アップグレード

| 種類 | 内容 | 解放条件 |
|---|---|---|
| 施設強化 | 各施設生産 ×2 (コスト = 施設コスト × 10) | 該当施設 5/25/50 個 |
| 全体強化 | 全生産 +25% | 累計クリスタル閾値 |
| 庭園拡張 | オフライン上限延長 (8h → 24h) | 水晶の泉 10 個 |
| なでなで強化 | 撫でバフ強化 | 撫で回数累計 |

## 6. 昇華 (Prestige)

- 条件: 今回の走行で累計 100 万クリスタル
- 星屑 = `floor( (累計 / 1e6)^0.5 × 10 )`
- 実行すると**物理庭園もリセット**(砂と水が消え、白紙の庭に戻る — 演出として気持ちいい)

## 7. オフライン進行

- 30 秒ごと + 購入時に NVS セーブ (構造体 + 最終時刻)
- 起動時: `(現在時刻 - 最終時刻) × 生産速度` を一括付与 (上限 8h → 庭園拡張で 24h)
- 復帰演出: ルミ `05_sleepy` → 「おかえり!この間に ◯◯ 個採れたよ」 (`03_happy`)
- 物理庭園にも、経過分に応じた結晶をまとめて生やして見た目を同期

## 8. 画面構成 (480×480)

```
┌────────────────────────────┐
│ HUD: 💎 12.3K  (+45.2 /s)  │  上段 ~80px
├────────────────────────────┤
│                            │
│   物理キャンバス 400×340    │  箱庭本体
│   (ルミは庭の中に立つ)       │
│                            │
├────────────────────────────┤
│ [水][砂][岩][削]  [施設][⚙] │  下部 ~60px
└────────────────────────────┘
```

- 数値は K/M/B/G 接尾辞、HUD 1Hz 更新、物理 30fps (LVGL の再描画は dirty region のみ)

## 11. 実装フェーズ

| Phase | 内容 |
|---|---|
| P1 | **物理エンジン** (落下砂 CA + LVGL キャンバス描画 + タッチで水/砂/岩/削) |
| P2 | 経済コア (生産/セーブ/オフライン) + HUD + 施設タブ |
| P3 | ルミ描画 (瞬きアニメ) + なでなで検知 + 表情差分 + セリフバブル |
| P4 | 施設エミッタ接続 (物理⇔経済の統合) + 昇華演出 |
| P5 | WiFi/NTP + スリープ画面 + 素材の正式取り込み (RGB565 変換パイプライン) |

技術メモ: 450KB のキャンバスは LVGL の標準ヒープでは足りないため、
`lv_mem_custom` を `heap_caps_malloc(SPIRAM)` に接続する / キャンバスだけ
PSRAM 直確保して `lv_img` + `lv_img_cache` で描く、のどちらかを採る (P1 で確定)。
