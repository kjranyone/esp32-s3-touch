# ゲームデザイン — 『ルミの水晶庭園』(v1)

放置系インクリメンタル + 美少女マスコット。タップ連打系クリッカーではなく、
**自動進行・経営判断主体**の idle ゲームとして設計する。

ハード前提: JingCai ESP32-4848S040C_I_Y_3 (480×480 タッチ, ESP32-S3R8, 16MB Flash,
WiFi, NVS, 常時通電デスク置き運用)

---

## 1. コアループ

1. 水晶庭園の施設が **自動でクリスタルを生産し続ける** (プレイヤーが何もしなくても育つ)
2. 蓄まったクリスタルで **施設を増やす / アップグレードを買う** → 生産速度が加速
3. 一定規模に達したら **星屑へ昇華 (prestige)** → リセット引き換えに恒久バフ
4. 電源を切っていた期間は **オフライン進行** として一括精算、ルミが報告してくれる

プレイヤーの能動操作は「施設・アップグレード購入」「なでなで」のみ。
数値の伸びを眺める・次の購入を計画するのが遊びの中心。

## 2. 資源

| 資源 | 役割 |
|---|---|
| **クリスタル** | メイン通貨。施設・アップグレードの購入に使う |
| **星屑** | 昇華報酬。恒久バフ通貨 (1個につき全生産 +1%、減衰しない) |

---

## 3. 生産施設 (5 種)

コストは個数 n ごとに `base × 1.15^n` (標準的な放置系カーブ)。

| 施設 | 初期コスト | 生産力 | フレーバー |
|---|---|---|---|
| 晶芽のつぼみ | 15 | 0.1 /s | 庭園の最初の一滴 |
| 水晶の泉 | 100 | 1 /s | 湧き出る光の雫 |
| 鉱脈の巣 | 1,100 | 8 /s | 地中で育つ結晶 |
| 星降る塔 | 12,000 | 47 /s | 星の光を集めて凝縮 |
| 月影の祭壇 | 130,000 | 260 /s | 夜だけ回転する禁斉の祭壇 |

## 4. アップグレード

| 種類 | 内容 | 解放条件 |
|---|---|---|
| 施設強化 | 各施設の生産 ×2 (コスト = 施設コスト × 10) | 該当施設を 5/25/50 個所有 |
| 全体強化 | 全生産 +25% など | 累計クリスタル閾値 |
| 庭園拡張 | オフライン進行の上限延長 (既定 8h → 24h) | 水晶の泉 10 個 |
| なでなで強化 | 撫でバフの効果/持続アップ | 撫で回数累計 |

## 5. 昇華 (Prestige)

- 条件: 今回の走行で累計 100 万クリスタル到達
- 獲得星屑 = `floor( (累計クリスタル / 1e6)^0.5 × 10 )` (要調整)
- クリスタル・施設・アップグレードはリセット、星屑バフと庭園拡張は保持
- ルミ用の専用セリフ/表情 (v2 で `08_proud` を追加)

## 6. オフライン進行

- 30 秒ごと + 購入時に NVS へセーブ (セーブデータ struct + 最終時刻)
- 起動時: `(現在時刻 - 最終時刻) × 生産速度` を一括付与
  - 時刻は WiFi + NTP (未設定時は RTC 経過時間で近似)
  - 上限: 既定 8 時間 (庭園拡張で 24h)
- 復帰演出: ルミが `05_sleepy` → 報告バブル → `03_happy`

## 7. なでなでバフ (唯一の"ちゃちゃ入れ"操作)

- ルミを上下にスワイプ → **10 分間 全生産 +10%** (クールダウン 5 分)
- クリッカー化しないよう、タップでは資源を増やせない
- 反応: `04_pet`

## 8. 画面構成 (480×480)

```
┌────────────────────────────┐
│ HUD: 💎 12.3K  (+45.2 /s)  │  上段 ~90px
│ [ルミ立ち絵 + セリフ]        │
│                            │  中央 ~320px
├────────────────────────────┤
│ [庭園][施設][昇華][設定]     │  下部タブ ~70px
└────────────────────────────┘
```

- **庭園タブ**: ルミ + セリフバブル + 生産概況
- **施設タブ**: 5 施設のリスト (所有数/コスト/生産力、タップで 1 個購入、長押しで ×10)
- **昇華タブ**: 星屑プレビューと実行ボタン
- **設定タブ**: WiFi 設定 / スリープ / セーブリセット
- 数値表示は K/M/B/G 接尾辞、HUD は 1Hz 更新 (LVGL の負荷対策)

## 9. セーブデータ (NVS)

```c
struct SaveV1 {
    uint32_t magic;        // 'LUMI'
    uint16_t version;      // 1
    uint64_t crystals;     // 小数 1 桁を x10 固定小数で保持
    uint64_t lifetime_crystals;
    uint16_t facility_count[5];
    uint16_t upgrades_bitfield;
    uint32_t stardust;
    uint64_t last_seen_unix;   // オフライン進行用
    uint32_t pet_count;
};
```

## 11. 実装フェーズ

| Phase | 内容 |
|---|---|
| P1 | ゲームループ (生産/セーブ/オフライン) + 施設タブ。ルミはプレースホルダ矩形 |
| P2 | 生成画像取り込みパイプライン (縮小 → RGB565 → LVGL) + 瞬きアニメ |
| P3 | なでなで検知 (LVGL ジェスチャ) + 表情差分切り替え + セリフバブル |
| P4 | 昇華 + WiFi/NTP + スリープ画面 |
