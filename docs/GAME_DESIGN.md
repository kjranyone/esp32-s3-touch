# ゲームデザイン — 『ルミの水晶庭園』(v3: ベルトスクロールアクション)

**ジャンル**: 2D ベルトスクロールアクション(くにお/リバーシティ系)+ 放置収入 + スキルツリー強化
**コンセプト**: クリスタルの精霊少女ルミが、汚された水晶庭園を敵から奪回していく。
戦闘で集めたクリスタルでツリーを伸ばし、より深い庭園へ。放置中も庭は少しずつクリスタルを産む。

ハード前提: JingCai ESP32-4848S040C_I_Y_3 (480×480 タッチ, ESP32-S3R8, WiFi, 常時通電)

> v1(物理箱庭インクリメンタル)→ v2(落下砂物理)の経緯は git 履歴参照。
> v3 でアクションに舵を切った理由: 「砂と水は地味」。桜井スキルはアクション寄りの原則集であり、
> ヒットストップ・ヒットマーク・画面振動が最も活きるジャンルへ移行。

---

## 1. コアループ

1. **戦う**: ステージを右に進み、波状で来る敵をコンボで蹴散らす(手応え重視)
2. **集める**: 倒した敵がクリスタルをドロップ、タップ(自動吸収)で回収
3. **強化する**: スキルツリーで攻撃/移動/射程/HP/放置収入を伸ばす
4. **深く進む**: 5 波ごとにボス。奥ほど敵と報酬が強くなる
5. **放置する**: 電源入りっぱなしの間も庭園は 0.5/s 程度のクリスタルを自動生産(IDLE スキルで倍増)

リスクとリターン (#006): 敵の攻撃圏に踏み込むほど攻撃が当たる(近接の本質)。
コンボ 3 段目は隙が大きいが威力 2 倍。

## 2. 操作 (仮想パッド + ボタン)

| 入力 | 動作 |
|---|---|
| 左仮想パッド (ドラッグ) | 8 方向移動(ベルト: 上下は奥行き、左右は進行) |
| ATK ボタン (連打) | 3 段コンボ。3 段目は威力 x2・隙大 |
| DASH ボタン | ダッシュ(移動速度 x2.2、発生に無敵 8F) |
| キャンバス縦スワイプ | ルミになでなで → 回復 + 攻撃バフ 30 秒 (スキルで強化) |

## 3. 敵 (一言で尖らせる #204)

| 敵 | 特性 |
|---|---|
| スライム | ゆっくり接近→体当たり。量で押す雑魚 |
| コウモリ | すばやい。接近→攻撃→後退を繰り返すヒットアンドアウェイ |
| ゴーレム | 遅い・硬い・攻撃は大振り(予備動作長)。ダッシュでの差し込みを促す |
| ボス (5 波ごと) | 攻撃パターン 2 種+大ダメージ。「攻略を考えさせる困難」(#105) |

## 4. 手応え仕様 (桜井スキル specs/effects を直接適用)

| 要素 | 仕様 |
|---|---|
| ヒットストップ | ヒット時 4F 全体停止(攻撃力と技ごとに係数、大→小に収束) |
| ヒットマーク | 判定重なりの位置に星形+衝撃波。3F で消す。明暗どちらでも見える白+黒縁 |
| ヒットフラッシュ | 被弾側を白 3F(明暗交互、#221) |
| ノックバック | 被弾方向へ速度注入、減衰。3 段目は大きく吹っ飛ぶ |
| 画面振動 | キル時 小(縦のみ)、ボス撃破 大(縦横+ランダム、強→弱収束) |
| ダメージ数字 | 浮遊上昇、クリティカル(3 段目)は大きく |
| リトライ | 転倒後 60F で即復帰、ペナルティなし(#116 迅速に)。死に演出は短く派手に |

## 6. 放置収入

- 電源オフ中の精算は WiFi/NTP 実装後に対応 (P5)
